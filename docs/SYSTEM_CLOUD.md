# 系统设置与其他系统云控

简体中文 | [English](SYSTEM_CLOUD.en.md)

## 独立入口

设置 → 系统设置云控。也可在游戏规则未就绪的页面打开独立入口。

支持以下只读来源：

| 来源 | 只读路径 | 展示方式 |
| --- | --- | --- |
| 系统设置数据库 | `/data/user_de/0/com.android.htmlviewer/databases/cloud_all_data.db`，`cloud_all_data` 表 | 动态发现列；列出全部包名、模块和状态，可搜索、分页 |
| 通用云控备份 | `/data/system/common_cloud_backup.xml` | 按 `cloud-data-item` 的 `moduleName` 展示；`moduleString` 作为规则原文 |
| 窗口管理缓存 | `/data/system/cloud_control/cloud_control_cache.json` | 整份窗口管理 JSON 作为一个规则，保留完整源原文 |

路径为当前设备已观测格式，不代表所有 ROM 使用同一缓存。不存在、格式不兼容、文件过大和源数据变化均以可恢复错误显示，不创建系统文件，也不自动下载云控。

## 查看与编辑

- 来源选择器显示记录数；长按来源可查看完整路径、读取限制和结构化错误。再查看包名、模块、类型、解码层数、元数据及完整源数据；原文可选择复制。
- 此入口及嵌套编辑页的标题状态固定为“本地草稿 · 未应用”，不会借用游戏钩子的“规则已应用”状态。
- 选择“编辑本地草稿”，按原始字段名逐层编辑 object / array / string / number / boolean / null。支持搜索、60 项分页、添加、删除、改名、类型替换和数组排序。
- 字符串中的 JSON 对象 / 数组可选择结构化编辑，最多解码 4 层，并在修改时保留字符串包装层数。未知字符串仍为字符串；已验证的 PID / MIGT 等字符串继续使用分项编辑器。
- 严格 JSON 校验拒绝重复字段、宽松语法、超深 / 超多节点及数字精度损失，无法安全解析的内容保持原文，不静默修复或丢弃。
- “保存本地草稿”仅写入应用私有目录中的 `system-cloud-draft.json`，不进入 Joyose profile，也不会修改系统数据库、XML 或 JSON 缓存。
- 当前保留一份系统云控草稿，只有源指纹相同才恢复；保存另一条规则会替换该草稿。文件来源的指纹包含完整源文件摘要，源更新后必须重新选择，不误取同名记录。

**系统规则的实际覆盖尚未适配。** 通用可视化编辑不意味着这些字段已被系统采纳。这里不提供“应用到系统”按钮，不将任意系统规则交由 Joyose 钩子应用。

## 读取边界

既有设备记录中，应用界面将系统设置数据库显示为“缺失”，而 ADB shell 可见空数据库。此差异尚未确认解决；ADB 可见或空库不代表应用已读取到有效记录。

数据库使用只读连接，筛选参数绑定；完整记录按包名、模块、指纹及可用时的行标识读取。单条原始数据超过 128 KiB 或身份字段无法完整读取时，保留清单状态但不提供截断后的假指纹。来源固定为上表路径，不接受任意文件读取路径。

游戏规则与此入口完全分开：原有游戏规则的“保存并应用”仍按已验证的 Joyose 流程工作。请勿将未知系统字段的本地草稿保存理解为系统实际生效。
