# 列表具名字段

简体中文 | [English](NAMED_FIELDS.en.md)

具名字段以单键对象保存，名称是 JSON 键，不是界面别名。例如：

```json
[{"enabled": false}]
```

## 新建与改名

- 对象：点击“添加”，输入名称，再选择类型。
- 列表：选择“具名字段（保存为对象）”，输入名称，再选择类型。
- 已有普通列表项：`⋯ → 设为具名字段 → 输入名称 → 转换`。
- 具名字段：`⋯ → 改名`，修改名称后保留原值、类型和位置。

“普通列表项（无名称）”仍可使用，已有数据不自动转换。名称不能为空；同一对象内不能覆盖已有键。

## 编辑行为

- 开关只修改内部布尔值，不替换外层对象。
- 排序移动整个列表项，名称和值一同移动。
- “展开对象”可查看包装对象并添加其他字段。
- 重选当前类型不改数据；更换类型前需确认清空旧值。
- 本地 JSON 草稿在新建、转换或改名后定位到对应字段。

## 结构限制

将 `[false]` 转为 `[{"enabled":false}]` 会改变列表项类型，目标规则的读取方必须支持该结构。转换前需确认，取消不改数据，也不会自动应用。

系统云控入口仅保存本地草稿，不写入系统数据库或缓存。
